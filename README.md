# 🛡️ Flow Shield | افزونه دور زدن محدودیت Google Flow

افزونه‌ای مدرن و بهینه‌سازی‌شده جهت رفع تحریم و محدودیت‌های منطقه‌ای **Google Flow** بدون نیاز به تغییر مداوم آی‌پی.

---

## 🚀 راهنمای نصب در مرورگرها

### ۱. نصب در Google Chrome / Edge / Brave
1. فایل زیپ نسخه کروم را از بخش [Releases](../../releases) دانلود و استخراج (Extract) کنید.
2. وارد صفحه `chrome://extensions` شوید.
3. کلید **Developer mode** را از گوشه بالا سمت راست روشن کنید.
4. روی دکمه **Load unpacked** کلیک کرده و پوشه `chrome` را انتخاب نمایید.

### ۲. نصب در Firefox
1. وارد آدرس `about:debugging#/runtime/this-firefox` شوید.
2. روی دکمه **Load Temporary Add-on...** کلیک کنید.
3. فایل `manifest.json` داخل پوشه `firefox` را انتخاب کنید.
